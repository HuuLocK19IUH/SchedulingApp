# Ảnh chụp màn hình — TODO

Chưa có ảnh chụp thật trong repo (máy làm patch này không có trình duyệt
headless để chụp tự động, nên không bịa ảnh).

Lộc chụp 2 ảnh rồi bỏ vào thư mục này, đặt đúng tên file:

1. `dashboard.png` — tab **Lịch học**, lưới tuần HK1 (1280×800 trở lên).
2. `simulator.png` — tab **Mô phỏng đăng ký**, bảng so sánh các phương án.

Cách chụp:

```bash
npm run dev
# Mở http://localhost:5173, bấm tab Lịch học rồi chụp màn hình,
# sau đó bấm tab Mô phỏng đăng ký rồi chụp tiếp.
# Trên Windows: Win + Shift + S, hoặc bấm F12 rồi Ctrl + Shift + P → "Capture screenshot".
```

Xong rồi commit 2 file ảnh lên GitHub — mục "Screenshots" trong README
chính sẽ tự hiện ảnh.
